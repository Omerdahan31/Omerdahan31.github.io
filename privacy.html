Privacy Policy — Personal Assistant

Last updated: 31 October 2026

Personal Assistant is a private tool used only by its owner. No one else signs in to it.

Data accessed

With the owner's consent, it reads the owner's Google Calendar events and Gmail messages using read-only permissions (calendar.readonly, gmail.readonly). It never sends, deletes, labels or changes mail or calendar events.

How it is used

Events and messages are summarized, using the Anthropic API, and sent only to the owner's own private Telegram chat. The data is not sold, shared with third parties for advertising, or used to train models.

Storage

Credentials are kept on the owner's private server. Message summaries may be kept in the assistant's private database as part of the chat history.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
